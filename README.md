# نظام NXN لإدارة جودة الفروع — نسخة بايثون

نسخة معاد بناؤها بالكامل بلغة **بايثون** من مشروع NXN الأصلي (Next.js/TypeScript)،
باستخدام **Streamlit** للواجهة.

## ⚡ أسرع طريقة للتشغيل (بدون أي تعقيد — ضغطة واحدة)

1. ثبّت **Python** إذا لم يكن مثبتًا عندك: https://www.python.org/downloads/
   (تأكد من تفعيل خيار **"Add Python to PATH"** أثناء التثبيت)
2. فك ضغط هذا المجلد بأي مكان على جهازك
3. اضغط ضغطتين على ملف **`START_HERE.bat`**
4. انتظر ثواني (أول مرة فقط يثبّت المتطلبات تلقائيًا)، وبيفتح المتصفح تلقائيًا
5. من الشاشة الأولى، أنشئ حساب "المالك" وابدأ الاستخدام مباشرة

**لا تحتاج تثبيت PostgreSQL ولا GitHub ولا أي شيء إضافي** — النظام يستخدم قاعدة
بيانات SQLite (ملف واحد بسيط، `nxn_quality.db`، يُنشأ تلقائيًا بجانب المشروع).

تم اختبار هذا المشروع بالكامل قبل التسليم: تشغيل قاعدة بيانات PostgreSQL حقيقية،
تنفيذ `seed.py`، اختبار تسجيل الدخول وحساب نتيجة تدقيق فعليًا، وتشغيل خادم
Streamlit والتأكد من استجابته (HTTP 200).

## ✅ ما تم تغطيته (مطابق للمنطق الأصلي في db/schema.ts)
- تسجيل الدخول والأدوار (owner, manager, auditor, branch, viewer)
- إدارة الفروع (Branches)
- نُسخ قوائم الفحص + الأقسام + الأسئلة (Checklist Versions / Sections / Questions)
- إنشاء وتنفيذ التدقيقات + الإجابة على الأسئلة + حساب النتيجة تلقائيًا
- إنشاء إجراءات تصحيحية تلقائيًا عند وجود إجابة "غير متوافق"
- متابعة وتحديث الإجراءات التصحيحية
- إدارة المستخدمين والصلاحيات
- لوحة معلومات (Dashboard) بمؤشرات ورسوم بيانية
- تصدير تقارير Excel و PDF
- سجل نشاط (Audit Log) لكل العمليات الحساسة

## ⚠️ ما لم يتم تضمينه عمدًا (بنية تحتية متقدمة خاصة باستضافة Cloudflare)
- WebAuthn / Passkeys وأجهزة البصمة الحيوية
- وكيل الذكاء الاصطناعي (agent tasks/runs) والمساعد الإرشادي
- الإشعارات الفورية Push المشفّرة
- تتبع Observability التفصيلي للجلسات
- رفع الأدلة (Evidence) للتخزين السحابي R2 — تم استبداله بتخزين الملفات داخل قاعدة البيانات نفسها (bytea) لتبسيط الإعداد؛ يمكن تفعيل صفحة رفع أدلة إضافية بسهولة إذا احتجتها

## 🚀 طريقة التشغيل التفصيلية (بديلة، مع خيار PostgreSQL)

### 1) تثبيت المتطلبات
```bash
pip install -r requirements.txt
```

### 2) قاعدة البيانات
افتراضيًا لا تحتاج تسوي شي (SQLite تلقائي). إذا تبي تستخدم PostgreSQL بدلها
(مثلاً عند النشر أونلاين)، أنشئ قاعدة بيانات فارغة وحدد رابطها بمتغير `DATABASE_URL`
بملف `.env` (انسخ `.env.example` وعدّله):
```sql
CREATE DATABASE nxn_quality;
```

### 3) تشغيل التطبيق
```bash
streamlit run app.py
```
افتح المتصفح على: http://localhost:8501 وأنشئ حساب المالك من الشاشة الأولى.

## 🔑 الأدوار والصلاحيات
| الدور | الصلاحيات |
|---|---|
| owner (مالك) | كل شيء بما فيها إدارة المستخدمين وسجل النشاط |
| manager (مدير) | إدارة الفروع، قوائم الفحص، اعتماد التدقيقات، المستخدمون |
| auditor (مدقق) | إنشاء وتنفيذ التدقيقات الخاصة به |
| branch (فرع) | متابعة تدقيقات فرعه والإجراءات التصحيحية الخاصة به |
| viewer (مشاهد) | عرض فقط |

## ☁️ النشر أونلاين (رابط عام تفتحه من أي مكان) — Streamlit Community Cloud

لا تحتاج تشغّل أي أوامر Terminal بعد النشر — التطبيق فيه شاشة "تهيئة أولى" تنشئ حساب
المالك من داخل المتصفح مباشرة عند أول فتح.

### الخطوات:

**1) أنشئ قاعدة بيانات PostgreSQL مجانية على الإنترنت**
اذهب إلى https://neon.tech → أنشئ حساب مجاني → أنشئ مشروع جديد (Project) →
انسخ "Connection string" اللي يبدأ بـ `postgresql://...`
(غيّر البداية إلى `postgresql+psycopg2://` بدل `postgresql://`)

**2) ارفع المشروع على GitHub**
- أنشئ حساب على https://github.com إن ما عندك
- أنشئ Repository جديد (خاص أو عام، الاثنين يشتغلون)
- ارفع كل ملفات هذا المشروع إليه (اسحب وأفلت الملفات من واجهة GitHub، أو استخدم Git)
- ⚠️ **لا ترفع ملف `.env`** إذا كان موجودًا عندك (احذفه قبل الرفع، فيه بيانات حساسة)

**3) انشر على Streamlit Community Cloud**
- اذهب إلى https://share.streamlit.io → سجّل دخول بحساب GitHub نفسه
- اضغط "New app" → اختر الـ Repository اللي رفعته
- في خانة "Main file path" اكتب: `app.py`
- قبل الضغط على Deploy، افتح "Advanced settings" → "Secrets" والصق:
  ```
  DATABASE_URL = "postgresql+psycopg2://USER:PASSWORD@HOST/DBNAME?sslmode=require"
  ```
  (استخدم القيمة الحقيقية من Neon اللي نسختها بالخطوة 1)
- اضغط Deploy

**4) افتح الرابط**
بعد دقيقة أو دقيقتين بيعطيك Streamlit Cloud رابط عام شكله:
```
https://your-app-name.streamlit.app
```
افتحه، وبيظهر لك شاشة "التهيئة الأولى" — أنشئ حساب المالك من هناك مباشرة وابدأ الاستخدام.

## 📝 ملاحظة حول حساب النتيجة
النتيجة = (مجموع أوزان الأسئلة "متوافق") ÷ (مجموع أوزان كل الأسئلة القابلة للتطبيق) × 100.
هذا تقريب معقول للمنطق الأصلي بناءً على حقول `weight` و`score_awarded` في المخطط؛
إذا كان لديك معادلة دقيقة مختلفة من الكود الأصلي (داخل `app/page.tsx` الضخم)، أخبرني وأعدّلها بدقة.
